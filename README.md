# NOVA STUDY — منصة الدراسة الذكية

واجهة عربية متجاوبة لمنصة تعليمية حديثة بتصميم فضائي داكن مستوحى من لوحة NOVA STUDY المرجعية. تعمل بدون إطار واجهات، وتقدم تجربة كاملة على سطح المكتب والهاتف.

## المزايا

- لوحة رئيسية لعرض تقدم اليوم ووقت المذاكرة والدروس والأسئلة.
- مواد دراسية ببطاقات تقدم ملونة.
- مكتبة ملفات مع البحث والمعاينة والرفع.
- خطة مذاكرة ومهام قابلة للإنجاز مع حفظ الحالة محليًا.
- اختبارات وإحصائيات أداء وصفحات داخلية متكاملة.
- مساعد دراسي تفاعلي مع اقتراحات ومحادثة تجريبية.
- مؤقت جلسة تركيز، مركز إشعارات، ووضع داكن/فاتح.
- شريط تنقل جانبي لسطح المكتب وشريط سفلي مخصص للهاتف.
- تطبيق PWA قابل للتثبيت والعمل من الكاش.

## التشغيل

```bash
npm start
```

ثم افتح:

```text
http://localhost:3000
```

للتطوير مع إعادة التشغيل التلقائي:

```bash
npm run dev
```

## الاختبارات

```bash
npm test
```

## أهم الملفات

| الملف | الدور |
|---|---|
| `index.html` | واجهة التطبيق الكاملة والتفاعلات |
| `assets/nova-books.webp` | الرسم الرئيسي المحسن للويب |
| `manifest.webmanifest` | تعريف تطبيق NOVA STUDY القابل للتثبيت |
| `sw.js` | التخزين المؤقت والعمل دون اتصال |
| `server/static.js` | خادم المعاينة المحلي |
| `tests/nova-smoke.test.js` | اختبارات البنية والهوية وصحة JavaScript |
