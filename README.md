# فهيم — منصة الدراسة الذكية

«فهيم» تطبيق عربي Mobile First لتلخيص المواد وتنظيم المذاكرة وبناء الخرائط الذهنية. صُمم كأداة إنتاجية أكاديمية احترافية، لا كروبوت محادثة؛ حيث تعمل قدرات الذكاء الاصطناعي كمحرك مساعد في الخلفية بينما يبقى الطالب هو من يبدأ ويبني ويعدّل.

## ما الذي يقدمه التطبيق؟

- **مكتبتي ولوحة الدراسة:** حفظ مواد الطالب ومتابعة عدد الملخصات والبطاقات المتقنة.
- **استيراد ومعالجة المحتوى:** رفع ملف أو لصق نص المادة، ثم اختيار نمط التلخيص المناسب.
- **قارئ ملخص تفاعلي:** عرض الخلاصة، النقاط المهمة، والقوانين أو المصطلحات المستخرجة من النص.
- **كانفاس خريطة ذهنية:** صفحة بيضاء يبدأها الطالب بعقدة مركزية قابلة للتحرير، بدون مواد أو أشكال تجريبية جاهزة.
- **الرسم الحر بالقلم:** قلم، تظليل، ممحاة، وألوان دراسية.
- **Smart Shape Smoothing:** تحويل الرسم اليدوي للدائرة أو المستطيل أو السهم إلى شكل منتظم.
- **بطاقات مراجعة:** بطاقات سؤال/جواب مع تقييم صعوبة الاسترجاع.
- **تصدير ومشاركة:** حفظ الخريطة كـ PDF للطباعة، PNG 4K، أو SVG متجهي.
- **PWA:** ملف Manifest و Service Worker لتجربة تطبيق قابلة للتثبيت والعمل من الكاش.

## تشغيل محلي

```bash
npm start
```

يفتح الخادم التطبيق على:

```text
http://0.0.0.0:3000
```

أو افتح `index.html` مباشرة في المتصفح.

## التطوير

```bash
npm run dev
```

## الاختبارات

```bash
npm test
```

تتحقق الاختبارات من:

- وجود مسار الدراسة العربي المطلوب داخل الواجهة.
- بدء الخريطة الذهنية بدون محتوى تجريبي لمواد محددة.
- سلامة JavaScript المضمّن في `index.html`.
- توافق Manifest مع هوية فهيم.

## أهم الملفات

| الملف | الدور |
|---|---|
| `index.html` | التطبيق التفاعلي الكامل |
| `souqi.html` | نسخة توافقية من التطبيق لمن يفتح المسار القديم |
| `manifest.webmanifest` | تعريف PWA وهوية التطبيق |
| `sw.js` | كاش التطبيق للعمل دون اتصال |
| `server/static.js` | خادم ثابت بسيط للمعاينة والتشغيل |
| `docs/FAHEEM_DESIGN.md` | وثيقة فكرة وتصميم التطبيق نصيًا |
| `tests/faheem-smoke.test.js` | اختبارات الدخان الخاصة بالتطبيق |

## ملاحظة مهمة

النموذج الحالي يطبق تجربة الواجهة والتفاعل محليًا. قراءة PDF والصوت والفيديو بتلخيص عميق تحتاج لاحقًا إلى ربط خدمات معالجة ملفات ونماذج ذكاء اصطناعي خلفية.
